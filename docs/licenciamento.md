# Sistema de Licenciamento

## Tipos de Licença
- **BASIC**: Acesso limitado.
- **PRO**: Recursos avançados de TV e Totem.
- **MASTER**: Controle total de multi-unidades.

## Validação Offline
As licenças possuem uma validade "grace period" (padrão 7 dias). Se a unidade Enterprise não conseguir "falar" com a Master por mais de 7 dias, o sistema bloqueia preventivamente.
