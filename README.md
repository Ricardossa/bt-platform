# BT Platform (Master)

## Visão Geral
A **BT Platform** é o sistema central de gestão do ecossistema BT Queue. Sua responsabilidade é gerenciar o ciclo de vida das unidades Enterprise, incluindo licenciamento, faturamento e distribuição de atualizações.

## Principais Recursos
- **Gestão de Empresas**: Cadastro e monitoramento de unidades.
- **Módulo Financeiro**: Controle de MRR, planos e contratos.
- **Updates OTA**: Geração e distribuição de pacotes de atualização remota.
- **Central de APKs**: Repositório e download de aplicativos Android nativos.

## Requisitos de Sistema
- PHP 8.1 ou superior.
- MariaDB 10.6 ou superior.
- Extensões PHP: `pdo_mysql`, `curl`, `zip`, `json`.
